# Milestone 1 Review — Playable Foundation

> QA Engineer and Critical Reviewer · 2026-11-23

## Delivered

A playable night-time Slums district: a 97×68-tile generated grid with 41+ buildings (10 named landmarks with signs and descriptions), a park, alleys, crosswalks, parked cars, lamps and props. Walk/run movement with collision and an integer-zoom camera. 14 named NPCs who wander, bark, talk (greeting, night and grudge pools), and react to being shoved by temperament, with bystander reactions and short-term grudges. Day/night lighting with neon. Main menu, character creation with a live sprite preview, HUD, dialogue, pause menu, and keyboard and controller support.

## Bugs found and fixed during review

1. **Lost taps:** Phaser `JustDown` drops a key pressed and released within one frame, so quick E taps did not open dialogue. Fixed by latching from `keydown` events (ADR-008).
2. **Crosswalk stripes** were oriented like stop lines. Fixed so the bars run parallel to traffic.
3. **Camera too far out** (characters about 32 px on a 1080p screen). The zoom target is now ~16 tiles of vertical view.
4. **Collision fallback** reverted by `−dx` instead of to the original position. Fixed before tests landed.
5. **Missing pixel-font glyphs** (▸ rendered as a comma in Press Start 2P). Removed.

## Critical review: challenged decisions

- *"Phaser should own the simulation."* Challenged and documented (ADR-002). Running the simulation as a pure package inside Phaser's loop is what makes save validation, replays and the 45 headless simulation tests possible.
- *"PostgreSQL, Redis and WebSockets from day one."* Rejected for M1 (ADR-006). They are specified, not deployed.
- *"Isometric like the reference image."* Weighed against GTA-style readability and collision simplicity; we chose oblique ¾ with the reference's palette and density (ADR-007).
- **Local saves moved from M6 to M2** (R-M1-3): the creature loop without persistence is not a real loop.
